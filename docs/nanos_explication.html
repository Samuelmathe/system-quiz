Rôle des Nanos dans le système

La Arduino Mega est le centre (DMX, logique jeu, relais PC). Les Nanos sont des cartes légères déportées dans la salle :

Équipe buzzer_nano_equipe.ino Un buzzer par équipe. Envoie « j’ai buzzé » à la Mega.
Animateur nano_animateur_final.ino Deux boutons : valider (bonne réponse) ou refuser (faux).
Son nano_son_final.ino Reçoit ordres de la Mega, joue les MP3 sur carte microSD (DFPlayer).

Chaque Nano a sa mission ; ils ne font pas tous la même chose. Seuls les buzzers et l’animateur émettent vers la Mega. Le nano son ne fait qu’écouter la Mega sur une autre adresse radio.

  • monEquipe — identité de la carte ; doit correspondre au numéro affiché au quiz et à settings.nbEquipes sur la Mega.
  • DEBOUNCE_MS (25 ms) — ignore les tremblements mécaniques du bouton.
  • COOLDOWN_MS (250 ms) — évite d’envoyer 10 buzz si on reste appuyé ; garde une bonne réactivité.
  • Watchdog (WDT 2 s) — redémarre la carte si le programme se bloque.

À chaque appui validé, la Nano émet un paquet vers l’adresse 00001. La Mega reçoit, ouvre la fenêtre 50 ms si plusieurs buzz, puis traite le gagnant.

Le champ seq s’incrémente à chaque envoi : la Mega ignore un paquet déjà vu (même seq), ce qui évite les doubles buzz accidentels.

Envoi avec AutoAck et jusqu’à 5 tentatives : la radio confirme la réception par la Mega.

void setup() {
    Serial.begin(9600);
    pinMode(boutonPin, INPUT_PULLUP);
    pinMode(moteurPin, OUTPUT);
    pinMode(LED_BUILTIN, OUTPUT);
    digitalWrite(moteurPin, LOW);
    wdt_enable(WDTO_2S);              // watchdog 2 secondes

    if (radio.begin()) {
        radio.setChannel(RADIO_CHANNEL);
        radio.setAddressWidth(5);
        radio.openWritingPipe(adresse);
        radio.setPALevel(RF24_PA_MAX);
        radio.setDataRate(RF24_250KBPS);
        radio.setCRCLength(RF24_CRC_16);
        radio.setPayloadSize(sizeof(RadioMsg));
        radio.setAutoAck(true);
        radio.setRetries(10, 15);
        radio.stopListening();        // mode émetteur uniquement

        Serial.print("Buzzer Equipe ");
        Serial.print(monEquipe);
        Serial.println(" pret !");
    } else {
        Serial.println("ERREUR : Module Radio non detecte !");
    }
}

La radio est configurée en émission seule (stopListening) : la carte n’écoute jamais, elle envoie seulement des buzz.

Nano équipe — loop()

buzzer_nano_equipe.ino · L.70 à 109
buzzer_nano_equipe.ino · L.70-109
void loop() {
    wdt_reset();
    bool btn = (digitalRead(boutonPin) == LOW);
    unsigned long now = millis();

    if (btn != lastBtn) {             // changement d'état bouton
        lastBtn = btn;
        lastChangeMs = now;
    }

    if (btn && (now - lastChangeMs) >= DEBOUNCE_MS) {
        if (now - lastSendMs >= COOLDOWN_MS) {
            lastSendMs = now;

            digitalWrite(moteurPin, HIGH);   // vibreur ON
            digitalWrite(LED_BUILTIN, HIGH);

            RadioMsg msg;
            msg.kind = 1;
            msg.value = (uint8_t)monEquipe;
            msg.seq = ++seqCounter;

            bool ok = false;
            for (int i = 0; i < 5 && !ok; i++) {
                ok = radio.write(&msg, sizeof(msg));
                if (!ok) delay(8);
            }

            delay(120);
            digitalWrite(moteurPin, LOW);      // vibreur OFF
            digitalWrite(LED_BUILTIN, LOW);
        }
    }
}

Pas de réception radio : émetteur pur. Le feedback vibreur + LED confirme l’appui au joueur même si la radio met quelques ms à répondre.

void envoyerSignal(uint8_t signal) {
    RadioMsg msg;
    msg.kind = 2;
    msg.value = signal;          // 88 ou 99
    msg.seq = ++seqCounter;

    bool ok = false;
    for (int i = 0; i < 5 && !ok; i++) {
        ok = radio.write(&msg, sizeof(msg));
        if (!ok) delay(10);
    }
}

Même structure que les buzzers, seul kind change : la Mega distingue buzz équipe (1) et commande animateur (2).

La Mega transmet ensuite au PC CMD_SENT:RESET_ALL ou CMD_SENT:RELANCE_PARTIEL et déclenche DMX + son.

static void playSonCmd(uint16_t cmd, uint8_t team) {
    if (!mp3OK) return;
    if (cmd != 200 && cmd != 201 && cmd != 202) return;

    ledFlashMs(25);
    dfStopTrack(monLecteurMP3);           // stop piste en cours
    drainDfSerial(monLecteurMP3, 12);

    if (cmd == 200) {
        jouerBuzzEquipeOuGenerique(monLecteurMP3, team);
    } else if (cmd == 201) {
        dfPlayTrack(monLecteurMP3, 2);   // 0002.mp3 victoire
        drainDfSerial(monLecteurMP3, DF_DRAIN_CMD_MS);
    } else if (cmd == 202) {
        dfPlayTrack(monLecteurMP3, 3);   // 0003.mp3 échec
        drainDfSerial(monLecteurMP3, DF_DRAIN_CMD_MS);
    }
}

static void pollRadioRx(void) {
    if (!radioOK) return;
    SonPayload rx;
    while (radio.available()) {
        radio.read(&rx, sizeof(rx));
        if (!sonPayloadValide(rx)) continue;
        if (dedupeSonRadio(rx)) continue;
        sonRxQueuePush(rx);              // file : max 12 paquets
    }
}

static void drainSonRxQueue(uint8_t maxPackets) {
    SonPayload p;
    for (uint8_t n = 0; n < maxPackets && sonRxQueuePop(p); n++) {
        traiterPaquetSonRadio(p);        // → playSonCmd()
    }
}

Au démarrage, sonProbeSdAtBoot() teste quels fichiers équipe existent (volume à 0, silencieux) pour accélérer les buzz suivants (~30 ms au lieu de ~100 ms).

nano_son_final.ino · L.234-261 — buzz équipe avec repli
static void jouerBuzzEquipeOuGenerique(DFRobotDFPlayerMini &df, uint8_t team) {
    if (team < 1 || team > 30) {
        dfPlayTrack(df, 1);              // 0001.mp3 générique
        return;
    }
    const uint8_t track = (uint8_t)(100 + team);   // eq.1 → 101 → 0101.mp3
    const uint32_t bit = (1UL << (team - 1));

    if (teamTrackKnownOk & bit) {
        dfPlayTrack(df, track);          // déjà testé au boot : lecture rapide
        return;
    }

    dfPlayTrack(df, track);
    if (dfPollFileMissing(df, DF_ERR_POLL_MS)) {
        dfStopTrack(df);
        dfPlayTrack(df, 1);              // repli 0001.mp3 si 01NN absent
        return;
    }
    teamTrackKnownOk |= bit;             // mémorise : piste OK
}

Le DFPlayer et la radio partagent le processeur. Le firmware alterne écoute radio et commandes DFPlayer :

nano_son_final.ino · L.170-207 — pause radio pendant commande DF
static void dfRadioPauseTx(void) {
    if (!radioOK) return;
    radio.stopListening();
    delayMicroseconds(1200);
}

static void dfRadioResumeRx(void) {
    if (!radioOK) return;
    delayMicroseconds(1600);
    radio.startListening();
}

static void dfPlayTrack(DFRobotDFPlayerMini &df, uint8_t track) {
    dfRadioPauseTx();
    df.playMp3Folder((int)track);        // ex. 101 → mp3/0101.mp3
    dfRadioResumeRx();
}

static void drainDfSerial(DFRobotDFPlayerMini &df, uint16_t totalMs) {
    const unsigned long t0 = millis();
    while (millis() - t0 < (unsigned long)totalMs) {
        pollRadioRx();                   // continue d'écouter la radio !
        drainSonRxQueue(1);
        while (df.available()) {
            (void)df.readType();
            (void)df.read();
        }
        delay(2);
    }
}
  • File d’attente (sonRxQ, 12 paquets) — les messages radio reçus pendant une lecture MP3 ne sont pas perdus.
  • pollRadioRx() — lit la radio dès que possible.
  • dfRadioPauseTx / dfRadioResumeRx — coupe l’écoute 1–2 ms le temps d’envoyer play/stop au DFPlayer.
  • drainDfSerial() — vide les retours du DFPlayer tout en continuant d’écouter la radio.
  • playSonCmd() — stoppe la piste en cours avant un nouveau son (évite blocage si valider/faux arrive vite après un buzz).
  • Re-arm écoute toutes les 400 ms — filet de sécurité si le chip radio sort du mode réception.

La Mega envoie plusieurs copies de chaque ordre son (rafales) ; le dedupe par seq évite de jouer deux fois le même son.

void loop() {
    const unsigned long now = millis();

    ledPulseUpdate();

    if (radioOK) {
        static unsigned long rearmEcouteMs = 0;
        if (now - rearmEcouteMs > SON_REARM_LISTEN_MS) {  // 400 ms
            rearmEcouteMs = now;
            radio.startListening();      // filet : réactive l'écoute
        }
        pollRadioRx();
        drainSonRxQueue(4);              // traite jusqu'à 4 sons en file
    }

    if (radioOK && now - dernierBattement > 2000) {
        ledFlashMs(20);                  // battement = système vivant
        dernierBattement = now;
    }
}
